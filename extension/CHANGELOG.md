# Changelog

## 0.4.0

- Geração e validação de HTML/CSS para LVGL 8.3 dentro do VS Code.
- Diagnósticos no painel Problemas com posição no documento.
- Fontes TCC Sans PT incluídas, com acentos em português.
- Configurações por projeto, suporte a múltiplas pastas e caminhos com espaços.
- Backend incluído; requer apenas Python 3.10 ou superior, sem instalação de pacotes Python.
- Cancelamento, limite de tempo e modo restrito do VS Code.
- Atualização transacional da saída, com proteção de arquivos editados manualmente.
- Exemplo de contador, trechos HTML e guia de elementos suportados.
